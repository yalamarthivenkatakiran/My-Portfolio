## Built With

Plain, dependency-free static web — no build step, no framework:

- HTML5 with inline CSS (custom properties, CSS Grid, Flexbox)
- Vanilla JavaScript (sticky nav, mobile menu, `IntersectionObserver` scroll reveals)
- [Google Fonts](https://fonts.google.com/) — DM Serif Display, Outfit, JetBrains Mono
- Hosted on [GitHub Pages](https://pages.github.com/)

Fully responsive, with `prefers-reduced-motion` support.

## Running Locally

No dependencies or build tooling required:

```bash
git clone https://github.com/yalamarthivenkatakiran/My-Portfolio.git
cd My-Portfolio
open index.html          # macOS — or just open the file in any browser
```

## Deploying

The site is served by GitHub Pages from the `main` branch, root folder. Any push to `main`
rebuilds and redeploys automatically:

```bash
git add -A
git commit -m "Update portfolio"
git push origin main
```
